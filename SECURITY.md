# Security

QT Suite runs local web servers on your PC. Most listen on 127.0.0.1 only. Beam also listens on your private network so your phone can reach it. Every Beam request needs the key that Beam makes on first run.

If you find a security problem, please report it privately through **GitHub, Security, Report a vulnerability** in this repository instead of opening a public issue. Include the steps to reproduce it and the version shown in Settings.
